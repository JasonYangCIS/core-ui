# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a tool that
manages versioning and changelogs with a focus on monorepos, but works just as well for
single-package repositories.

Run `npm run changeset` to add a new changeset describing your changes. On release, run
`npm run version` to bump versions and update changelogs, then `npm run release` to publish.

For more details: https://github.com/changesets/changesets
